# ユーザー登録画面 外部設計書

## 1. 画面概要

本画面は、新規ユーザーの情報を登録するための画面です。

### 画面への導線

- トップページ（`http://localhost:3000/`）に表示される「ユーザー登録」カードをクリックしてアクセスします
- DemoおよびTodo Appと横並びで表示されます

## 2. 画面レイアウト

入力フォームは表形式で表示され、左列に項目名、右列に入力部品を配置します。

## 3. 入力項目仕様

| 項目名   | 入力部品               | 必須/任意 | データ型 | 備考                                               |
| -------- | ---------------------- | --------- | -------- | -------------------------------------------------- |
| 姓       | テキストボックス       | 必須      | 文字列   | 最大50文字                                         |
| 名       | テキストボックス       | 必須      | 文字列   | 最大50文字                                         |
| 性別     | ラジオボタン           | 必須      | 選択肢   | 選択肢: 男性 / 女性 / その他                       |
| 生年月日 | デイトピッカー         | 必須      | 日付     | 形式: YYYY/MM/DD                                   |
| 所属部署 | プルダウン             | 必須      | 選択肢   | 選択肢: 営業部 / 開発部 / 人事部 / 総務部 / 経理部 |
| 役職     | テキストボックス       | 任意      | 文字列   | 最大30文字                                         |
| 備考     | 複数行テキストボックス | 任意      | 文字列   | 最大500文字                                        |

## 4. 画面項目詳細

### 4.1 姓

- **入力形式**: 1行テキストボックス
- **必須**: 必須
- **最大文字数**: 50文字
- **バリデーション**:
  - 未入力の場合: 「姓を入力してください」
  - 最大文字数超過: 「姓は50文字以内で入力してください」

### 4.2 名

- **入力形式**: 1行テキストボックス
- **必須**: 必須
- **最大文字数**: 50文字
- **バリデーション**:
  - 未入力の場合: 「名を入力してください」
  - 最大文字数超過: 「名は50文字以内で入力してください」

### 4.3 性別

- **入力形式**: ラジオボタン
- **必須**: 必須
- **選択肢**:
  - 男性
  - 女性
  - その他
- **バリデーション**:
  - 未選択の場合: 「性別を選択してください」

### 4.4 生年月日

- **入力形式**: デイトピッカー
- **必須**: 必須
- **表示形式**: YYYY/MM/DD
- **選択可能範囲**: 1900年1月1日 ～ 現在日付
- **バリデーション**:
  - 未選択の場合: 「生年月日を選択してください」
  - 未来日付の場合: 「生年月日に未来の日付は指定できません」

### 4.5 所属部署

- **入力形式**: プルダウン（ドロップダウンリスト）
- **必須**: 必須
- **選択肢**:
  - 営業部
  - 開発部
  - 人事部
  - 総務部
  - 経理部
- **初期表示**: 「選択してください」（プレースホルダー）
- **バリデーション**:
  - 未選択の場合: 「所属部署を選択してください」

### 4.6 役職

- **入力形式**: 1行テキストボックス
- **必須**: 任意
- **最大文字数**: 30文字
- **バリデーション**:
  - 最大文字数超過: 「役職は30文字以内で入力してください」

### 4.7 備考

- **入力形式**: 複数行テキストボックス（テキストエリア）
- **必須**: 任意
- **最大文字数**: 500文字
- **行数**: 5行表示
- **バリデーション**:
  - 最大文字数超過: 「備考は500文字以内で入力してください」

## 5. ボタン仕様

### 5.1 登録ボタン

- **ラベル**: 「登録」
- **配置**: フォーム下部中央
- **動作**:
  1. クリック時に全項目のバリデーションを実行
  2. バリデーションエラーがある場合、各項目の下にエラーメッセージを表示し、処理を中断
  3. バリデーションが全て成功した場合、入力データをサーバーに送信
  4. サーバーからの応答に応じて、成功/失敗メッセージを表示

### 5.2 キャンセルボタン

- **ラベル**: 「キャンセル」
- **配置**: フォーム下部中央（登録ボタンの右隣）
- **動作**:
  1. 入力内容を破棄
  2. 前の画面に戻る

## 6. バリデーション仕様

### 6.1 バリデーション実行タイミング

- **送信時バリデーション**: 登録ボタンクリック時に全項目のバリデーションを実行

### 6.2 エラー表示

- エラーメッセージは各入力項目の直下に赤文字で表示
- 複数エラーがある場合は、全てのエラーメッセージを表示
- エラーがある項目の入力部品は赤枠で囲む

### 6.3 バリデーションルール優先順位

1. 必須チェック
2. 形式チェック
3. 最大文字数チェック
4. 業務ルールチェック

## 7. 画面遷移

### 7.1 正常系

- 登録成功後 → ユーザー一覧画面に遷移し、成功メッセージを表示

### 7.2 異常系

- キャンセルボタンクリック → 前画面に戻る
- サーバーエラー発生 → 画面上部にエラーメッセージを表示

## 8. その他の仕様

### 8.1 初期表示

- 全ての入力項目は空の状態で表示
- 性別ラジオボタンは未選択状態
- 所属部署プルダウンは「選択してください」を表示

### 8.2 レスポンシブ対応

- スマートフォン表示時も表形式を維持
- 画面幅が狭い場合は項目名と入力部品を縦並びに変更

## 10. 備考

- 本画面は管理者権限を持つユーザーのみがアクセス可能
- 登録されたユーザー情報は即座にシステムに反映される
